# ProjectJS

### Данный проект демонстрирует мини веб-приложение, позволяющее динамически создавать информацию на странице.
### Создана веб-форма, через которую можно создавать в основной части страницы какую-либо информацию (текст, заголовки), приложение можно модернизировать и улучшать для более лучшего результата.
### В проекте используются пакеты npm, а также сборщик проекта parcel.

##### Чтобы запустить проект нужно выполнить следующую команду в консоли:
```npm run-script serve```

##### Для сборки проекта используется следующая команда:
```npm run build```
